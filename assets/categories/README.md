# Category illustrations

These 18 illustrations were generated with OpenAI ImageGen on 2026-10-09 for
the recipe category browser: six main categories and twelve subcategories.
They use a consistent cream-paper gouache cookbook style with warm brown,
gold and green colors, recognizable centered food and no text or logos.
The generated originals were resized to 384×384 PNGs for the app's 80px cards.

Filenames match the hosted category catalog's `image_key`. New category keys
should include a corresponding bundled image. Original full-resolution images
and review contact sheets are not required at runtime.
